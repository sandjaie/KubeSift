Focused user review

  1. Open bin/kubesift.app, or build with wails3 task package first. Search kind-dev-local and select a local context.
  2. Open Namespace, type kubesift and press Enter. Expect kubesift-explorer Pods. Reopen, type without choosing, then Escape; expect the original namespace.
  3. Drag the divider between Pods and details. Open Ask AI to stack the panes and drag vertically. Quit/relaunch and reconnect; expect independent remembered sizes.
  4. Switch Light/Dark in Settings and inspect text, focus and selection. Open both local contexts and confirm namespace and Pod selection remain independent.
