Office-laptop checklist · OCP 4.21 baseline

The maintainer deferred live testing to an office follow-up. The scoped run below records the cases exercised so far.

  1. With a restricted identity, list visible Projects, look up a Project by name and switch to it while Namespace list is denied.
  2. Check real namespace quotas and personal access decisions. Record allowed and forbidden results independently.
  3. Verify both request previews and cancellation send zero ProjectRequest POSTs. Confirm one disposable request, observe exactly one POST and record visible project-template effects.
  4. Verify delete dry-run leaves the original UID present and nonterminating. On an authorized disposable replacement, prove stale preconditions reject deletion and the replacement survives.
  5. Confirm deletion of the reviewed UID, observe termination or absence and record cleanup. Use a separately authorized verifier if the deleting principal loses read access.

Before testing, record the explicit context, server build, identities, disposable names or prefix, permitted reads and writes, and cleanup authority. Verify ownership and UID before each lifecycle operation.
