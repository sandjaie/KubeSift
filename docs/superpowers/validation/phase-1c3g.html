Phase 1C.3g validation

Cluster resources, API discovery and macOS launch sizing

Baseline 3147a6e includes 9e12a44. See the specification and plan.

Automated and kind integration

  • Repository source descriptions, documentation links, Go tests and vet, 72 frontend tests, lint and typecheck passed. Race runs covered kube, desktop and preferences; Wails bindings, production build and signed local package passed.
  • Native fake APIs cover fixed scope, modern Event absence fallback and denial, historical target replacement, lazy partial discovery, protected routes, expiry and LRU, malformed discovery, metadata projection, tampered cursors and exact numeric tokens.
  • Cluster discovery plus workload, networking, configuration (including strict Secret metadata), storage, access control and availability integration passed on kind-dev-local-a and kind-dev-local-b. The new suite checked all seven fixed kinds, Event-to-Pod UID resolution, namespaced and cluster Widget objects with a duplicate Kind, Endpoints, an exact large integer in YAML, both cluster and namespace isolation, and forbidden generic list and get under a restricted identity.

Packaged desktop evidence

Arm64 KubeSift 0.3.0 on macOS 27.0.1. Tested executable SHA-256: 10947c90c97eebb76bfb424b2a1943873eef306db194fbaaf83d8d78dd998bf0.

  • Opened a real Node detail and observed independent Ready and scheduling fields.
  • Opened the synthetic Event, followed its referenced Pod with a verified UID, and returned to the captured Event.
  • Opened the namespaced Widget from its CRD, saw the exact count 9007199254740993 in the YAML, used Copy displayed YAML (success reported by the app), and navigated back through inventory to the CRD. The clipboard bytes were not independently read.
  • APIServices v1.apps opened apps/v1. The API filter transferred focus to the resource selector on Tab. The detail divider narrowed from 52% to 36% by keyboard; both light and dark appearances were observed and System appearance restored.
  • Switching namespace to default kept Widget selected and showed an empty page. A second tab displayed the distinct B Node; returning to A restored its discovery selection and namespace.
  • On the attached large display the initial frame was 3,200 × 2,040 capture pixels (1,600 × 1,020 logical points), native zoom expanded it toward the display work area, and a second zoom restored the capped frame. Unit tests cover compact, offset, portrait and unplugged display work areas. A physical move between displays and a physical compact display were not tested.

Limits and delivery

No Gateway or snapshot stack was installed, and no such API was verified. Synthetic CRDs validate generic browsing, not extension semantics. Mounted-component race tests and the uncommon error and rendering matrix are not exhaustive. No narrow operating-system window frame was verified; the divider check narrowed the detail pane inside the supported workspace.

Removed the owned custom objects before their CRDs, cleaned temporary fixtures on both contexts, and removed isolated test kubeconfigs.

Independent review

Reviewer: whole_pr_review. Base and merge base 3147a6e; initial whole-PR candidate 21b8455. The initial review blocked merge on three defects.

  • KSF-001: Lease Events now use the fixed UID-checked object reader. The focused test demonstrated the failure and the signed retest loaded the legitimate empty Events tab.
  • KSF-002: Generic inventory accepts a valid server-defined list kind while checking the list API version and item identity. Tested with WidgetCollection in fake responses and real CRDs on both kind contexts.
  • KSF-003: Event-to-ConfigMap navigation uses the standard count-only Overview; the regression verifies one target GET and that data values do not cross the bridge. Event-to-Pod navigation was rerun in the package.
  • The discovery lifecycle regression checks test late cancellation, stale descriptor handles and connection-generation scope. The native retest restored the captured YAML after switching tabs, then cleared it on namespace change and explicit refresh.
