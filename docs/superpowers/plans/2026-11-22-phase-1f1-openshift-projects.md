# Phase 1F.1 OpenShift Projects implementation plan

> Separate implementation chat: use superpowers:executing-plans. Check tasks only against actual results.

**Goal.** Deliver Projects discovery, browse/switch, metadata/status, namespace quotas, personal access checks, reviewed self-service creation and conditional deletion.

**Architecture.** Build a dedicated Projects adapter on the existing connection-owned Go discovery and client-go transport. Keep review/execute in the native operation coordinator, route desktop calls through cancellable Wails reads and reuse React navigation, scope and result controls. No new SDK, oc subprocess or cluster installation. [Design and API contracts](../specs/2026-11-22-phase-1f1-openshift-projects-design.md)

**Baseline.** Develop at `6cd1d19` plus this planning commit. Start from updated develop on `feature/phase-1f1-openshift-projects` in the existing checkout.
