Proposed engineering defaults

  • Wails v3 baseline, client-go adapters, bounded session events and in-memory resource caches.
  • No silent cross-provider fallback; OS credential storage; explicit review of sensitive evidence sharing.
  • Helper trust keyed to resolved executable path, arguments and configured environment overrides; policy details in the security model.
  • Candidate UI stack: Tailwind/shadcn, terminal component and YAML editor. Specific dependencies not yet selected.
