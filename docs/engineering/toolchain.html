Development toolchain

Build environment

Use the repository pins when setting up a development machine or reproducing a build.

Tool Version or requirement
Go 1.27.3 in CI. The module declares Go 1.26.0. See go.mod.
Node.js and npm Node.js 26.13.0 in CI. Use npm with the checked-in package lock.
Wails CLI 3.1.0, matching the Wails module in go.mod.
Python Python 3 for documentation links and source checks.
macOS build tools Xcode Command Line Tools for native builds and packaging.

The CI workflow records the Go and Node.js versions used for automated checks.

Build and verify

Run these commands from the repository root.

npm ci
wails3 task build
scripts/check.sh

The build generates the desktop bindings and frontend bundle. For the macOS packaging command and launch instructions, see the README. Local packages are ad-hoc signed.

Local cluster tools

Install Docker, kind and kubectl when running the approved integration fixtures. See Local development for the cluster contexts, fixture commands and validation boundaries.

Validation history

The macOS package build sets a deployment target of 13.0. The Phase 1A validation report records the tested host, package hashes, startup measurements and verification limits.
