Thin Wails service: snapshot-bound connection calls, lazy helper trust, explicit sessions and fixed marker reviews. fixture.go validates the isolated source, loopback endpoints and ownership journal before issuing a marker target. validation.go is disabled without the explicit fixture environment; it validates both owned contexts, marks readiness only after actual frontend Ping and records bounded numeric-only renderer evidence under .local/phase1a (4 MiB file cap). No frontend path, executable, payload blob or arbitrary local command is accepted. Domain policy remains in the framework-independent services.

explorer.go exposes independent sources, cancellable connections and helper settings through one shared native core.

workloads.go extends ExplorerService with a 16-entry cancellable read registry and thin workload, networking and log methods; workloads_test.go protects cancellation ownership. Domain bounds and UID policy remain in internal/kube.
