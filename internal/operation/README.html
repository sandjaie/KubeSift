Prepared marker operations

Framework-independent Phase 1A prepare/review/execute for ks-marker. Opaque five-minute tokens bind connection generation, namespace, UID, resourceVersion and marker value. At most 128 reviews and 256-byte marker values are retained. Execution consumes the token before network work, revalidates identity through guarded connections and sends one update with UID/version preconditions. Unknown write outcomes require inspection and a new review. The desktop adapter additionally restricts access to its validated local fixture configuration.
