App owns explicit context/helper/marker controls and the shared register/activate/stop path. bridge.ts tracks event listeners and acknowledgements. state.ts supplies App’s namespace/connection-scoped Pod selection and target, counts accepted session-error events cumulatively, routes by identity and retains at most 1 MiB history per session; App displays the newest 64 KiB of each log. Terminal.tsx mounts xterm across tab switches, blocks OSC links/clipboard actions, resizes and acknowledges only parsed bytes. validation.ts times fixed split-marker terminal probes after xterm parse; profile.ts runs the explicit fixture-guarded packaged eight-session/600-second/20-cycle profile using those same UI paths. state.test.ts remains the single focused frontend safety test: explicit namespace/session targeting, cumulative error evidence, injected owned-stop failure and echoed probe rejection.
